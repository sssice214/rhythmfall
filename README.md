# RHYTHMFALL

**把 osu!mania 做进了 Minecraft！** 一个独立的 Fabric 模组，在 Minecraft 1.21.1 里完整实现 osu!mania 风格的下落式音游——4K/5K/6K/7K 全键数、直接读取 osu! 官方谱面（.osu / .osz）、真实变速变调、服务端排行榜。单机可玩，联机共用一条榜。

> 在方块世界里，打出属于你的 Perfect。

---

## ✨ 功能总览

### 核心玩法
- **下落式音游**：音符沿轨道落下，在判定线按键击打
- **五档判定**：`Perfect ±50ms / Best ±100ms / Good ±150ms / Bad ±200ms / Miss`
- **长条（Hold）**：头部判定 + 按住期间每 **0.3 秒**追加一个 Perfect 判定点；中途松手断连、重新按住可恢复；按住时播放持续「咻」风声（松手/退出立即停止，零底噪）
- **波纹特效**：每次击打在判定点扩散彩色波纹（高/低特效两档）
- **合成音效**：击打「哒」声实时合成，无采样文件
- **连击 / 得分 / 准确率** 全部实时显示
- **歌曲速度 ×0.5 ~ ×2.0**：音乐与谱面同比变速**变调**（osu DT 同款），开局前在难度页调节
- **打歌中滚轮调流速** ×0.5 ~ ×3.0，右侧面板实时显示
- **空格暂停**（4K）/ **TAB 暂停**（5K/7K 空格被中轨道占用，暂停键独立可在控制设置修改）；暂停时谱面与音乐完全冻结，按任意轨道键继续
- **切出窗口自动暂停**（防止挂机后台放歌）
- **AUTO 自动演奏**：观赏模式，判定显示 AUTO 且不计入排行榜
- 打歌时玩家无法主动移动（MC 界面机制），外物推动（水流/活塞/实体）照常生效；退出音游后按住的 WASD 立即恢复移动

### 谱面系统
- **直接读取 osu!mania 官方 .osu 谱面**：键数取自 CircleSize、背景图自动作为封面、仅接受 Mode: 3
- **.osz 包自动解包**：把 .osz 丢进谱面文件夹，游戏内点「刷新」即自动解包并出现在列表
- JSON 谱面同样支持
- 两种谱面来源：
  - `config/rhythmfall/charts/`（本地文件夹，即放即用，文件名不限字符）
  - 模组内置 `assets/rhythmfall/charts/`（随整合包分发，适合服务器统一曲库）
- 封面**异步解码、等比缩放不变形**：进选曲界面即显示

### 界面
- 选曲界面：横向轮播封面卡片（滚轮/方向键）、随机选曲、一键刷新、全屏不透明底
- 难度选择页：先选歌后选难度、难度过多支持**滚轮翻页**、开始前可调歌曲速度
- 首次进入的配置界面：流速 / 延迟校准 / 特效档位 / 音符音效 / 音乐开关 / 双音量 / 自动演奏
- 游玩界面：左侧连击 + 实时排行榜，右侧封面 / 曲名 / 难度 / 键数 / 流速面板
- 结算界面：SSS~D 评级、得分、准确率、最大连击、五档判定统计、本局速度、一键重试
- 全部文字与图片走 widgets 渲染通道——在 ModernUI 等字体接管类整合包中依然清晰

### 联机
- **服务端只承担排行榜**：每谱面每人保留最高 acc、TOP 50、结算自动提交
- 打歌时左侧排行榜**实时浮动**（你的条目随完成度上下爬）
- 谱面全部保存在玩家本地，**服务端零谱面占用**（仅收发几 KB 成绩记录，全异步不占主线程）
- 单机可玩（单人世界的内部服务端同样记录成绩）

### 指令
| 指令 | 权限 | 说明 |
|---|---|---|
| `/rhythmfall` | 所有人 | 打开音游界面（等效右键） |
| `/rhythmfall <玩家>` | OP 2 | 给指定玩家打开界面，支持 `@a` `@p` 等选择器 |
| `/rhythmfall dev` | OP 2 | 打开**开发者面板**（见下） |

**开发者面板**：内置「自动打歌」开关——开启后进入打歌由系统自动演奏，但判定正常显示 Perfect/Best（不显示 AUTO 徽章）、结算显示真实评级，方便录制演示画面。**自动演奏的成绩一律不计入排行榜。**

## 🎹 默认键位

| 键数 | 轨道键（左→右） | 暂停 |
|---|---|---|
| 4K | D F J K | 空格 / TAB |
| 5K | D F 空格 J K | TAB |
| 6K | S D F J K L | TAB |
| 7K | S D F 空格 J K L | TAB |

- 轨道键**不注册为全局按键**（存于 `config/rhythmfall/client.json` 的 `laneKeys4~7`，GLFW 键码可直接改）——绝不干扰正常游戏的移动/跳跃
- 暂停键可在 Minecraft 控制设置 → Rhythmfall 分类中修改

## 📀 安装使用

1. Minecraft **Java 版 1.21.1** + Fabric Loader（0.20.x）+ Fabric API
2. 把 `rhythmfall-1.1.0.jar` 放入 `mods/` 文件夹（单人客户端装；若要联机排行榜，服务器也装同一个 jar）
3. 进世界后：右键「音游机」方块 / 手持「节奏控制器」右键 / 输入 `/rhythmfall`，三种方式任选
4. 把 osu! 谱面（.osz 或解压后的文件夹）放进 `config/rhythmfall/charts/`，游戏内点「刷新」

**谱面文件夹结构**：
```
charts/
└─ 歌曲名/
   ├─ xxx.osu          （谱面，可多个难度）
   ├─ audio.mp3/ogg    （音频，osu 会自动指向）
   └─ bg.jpg           （背景图，自动作为封面）
```

## 🛠 构建

```bash
# 需要 JDK 21
./gradlew build
# 产物：build/libs/rhythmfall-1.1.0.jar
```

## 📁 目录结构

```
src/main/java/io/wifi/rhythmfall/
  Rhythmfall.java        公共入口（全局 IO 线程池）
  RhythmfallClient.java  客户端入口（键位、防移动、失焦暂停）
  RhythmfallServer.java  服务端入口（排行榜 + /rhythmfall 指令）
  beatmap/               谱面模型与 osu!mania 解析器
  client/                谱面扫描（含 .osz 解包）、封面纹理、配置、排行榜客户端
  server/                服务端成绩存储（JSON 落盘）
  network/               网络包（排行榜 3 个 + 打开 GUI/开发者面板 2 个）
  screen/                选曲 / 难度 / 配置 / 打歌 / 结算 五个界面 + 文字图片渲染层
  audio/                 OGG/MP3 播放（变速变调）+ 合成音效引擎
  content/ block/ item/  节奏控制器物品与音游机方块
assets/rhythmfall/charts/  内置谱面目录（可放入随包分发的谱面）
```

## ⚙️ 判定与计分

| 判定 | 窗口 | 得分 |
|---|---|---|
| Perfect | ±50ms | 300 |
| Best | ±100ms | 250 |
| Good | ±150ms | 200 |
| Bad | ±200ms | 50 |
| Miss | 超时 | 0（断连） |

准确率 = Σ(判定分) / (判定数 × 300)。评级：SSS(100%) / SS(98%) / S(95%) / A(90%) / B(80%) / C(70%) / D。
